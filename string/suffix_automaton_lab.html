図と更新途中の読み方

各ノードの文字列は、現在追加中の接頭辞に実在する部分文字列のうち、その時点の文字遷移を root からたどって到達するものです。文字列一覧は説明用に計算しており、元の C++ が保存しているデータではありません。

更新途中では、同じノード内の endpos が違ったり、len・link と到達する文字列の長さが一致しなかったりします。clone をコピーした直後は、まだ入ってくる経路がなく「到達なし」と表示されます。遷移を付け替えると、短い文字列が移動します。

link 未設定（−1）のノードは、木の右側に独立して表示します。root の link = −1 は正常です。赤の破線は前の操作時点の矢印を、現在のノード位置に重ねたものです。

図が横に長いときは横スクロールできます。ノードをクリックするか「状態」を選ぶと、含む文字列と終点集合を確認できます。

まず「次の clone 直前へ」を押し、「1操作 →」でコピー・長さ変更・経路変更・link 変更を順に観察してください。
