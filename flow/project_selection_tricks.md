# 燃やす埋める問題でよく使うテクニック

各要素を「選ぶ / 選ばない」の二択で決める最適化を、最小カットに帰着するためのメモ。以下では、目的関数を**最小化するコスト**として扱う。利益を最大化する場合は、符号を反転してから変換する。

## 選択とカットの対応

始点を $s$、終点を $t$ とし、カットで頂点を $s$ 側の集合 $S$ と $t$ 側の集合 $T$ に分ける。

- $x_v=1$：要素 $v$ を選ぶ。頂点 $v$ を $S$ に置く。
- $x_v=0$：要素 $v$ を選ばない。頂点 $v$ を $T$ に置く。

カット容量に加算されるのは、**$S$ から $T$ に向かう辺だけ**。逆向きの辺は加算されない。容量 $w\ge 0$ の辺は、次のコストを表す。

| 辺 | コスト $w$ がかかる条件 |
| --- | --- |
| $s\to v$ | $x_v=0$（選ばない） |
| $v\to t$ | $x_v=1$（選ぶ） |
| $u\to v$ | $(x_u,x_v)=(1,0)$ |

負の容量は使えないため、元のコストを「選択によらない定数 $K$ ＋ カット容量」に分解する。答えは最大流そのものではなく、$K+\operatorname{maxflow}(s,t)$ になる。

## 1変数のコストを辺に変換する

選ばないときのコストを $B$、選ぶときのコストを $A$ とする。$A,B$ は負でもよい。1列目が $x_v=0$、2列目が $x_v=1$ に対応する。

$$
\begin{pmatrix}B&A\end{pmatrix}
=\begin{pmatrix}m&m\end{pmatrix}
+\begin{pmatrix}B-m&A-m\end{pmatrix},\qquad m=\min(A,B).
$$

$m$ を定数 $K$ に加え、残りを非負容量の辺にする。

- $A\ge B$：$K$ に $B$ を加え、$v\to t$ に容量 $A-B$ の辺を張る。
- $A<B$：$K$ に $A$ を加え、$s\to v$ に容量 $B-A$ の辺を張る。

例えば「選ぶと利益 $5$」は $(B,A)=(0,-5)$ というコストになる。$K$ に $-5$ を加え、$s\to v$ に容量 $5$ を張れば、選んだときは $-5$、選ばないときは $-5+5=0$ を再現できる。

### 実装

以下のラムダ式は `main` などの関数内の同じスコープに、`add_unary`、`add_pairwise` の順に定義して使う。引数の順序は常に「選ばないとき、選ぶとき」とする。`offset` は定数 $K$ を保持する。

C++20 のテンプレートラムダを使い、グラフの容量・コスト・`offset` の型を `T` に統一する。`T` は `int` または `long long` とし、計算途中の値も含めて収まる型を選ぶ。コストの引数も同じ型で渡す（`mf_graph<long long>` なら `0LL` など）。

```cpp
auto add_unary = []<class T>(mf_graph<T> &g, int s, int t, int v, T cost0, T cost1, T &offset) {
    if (cost0 <= cost1) {
        offset += cost0;
        g.add_edge(v, t, cost1 - cost0);
    } else {
        offset += cost1;
        g.add_edge(s, v, cost0 - cost1);
    }
};
```

## 最大化を最小化に変換する

1. 禁止条件とは分けて、最大化したい利益の総和 $f(x)$ を書く。
2. コストを $E(x)=-f(x)$ とする。利益も損失も含めて、目的関数全体の符号を反転する。
3. $E(x)$ を定数と非負容量の辺に分解する。1変数の項は上の変換を使い、2変数の項は次節の劣モジュラ条件を確認する。
4. 辺で表現できる禁止条件を、違反時に **$+\infty$ のコスト**がかかるように追加する。具体的な辺と有限値による代用は後述する。
5. 最小コスト $E_{\min}=K+\operatorname{maxflow}(s,t)$ を求め、最大利益を $-E_{\min}$ として返す。

$$
\max_{x\text{ が制約を満たす}}f(x)
=-\min_{x\text{ が制約を満たす}}(-f(x)).
$$

禁止条件は許される選択の集合を定めるもので、符号反転する数値項ではない。最小化のグラフに負の無限大の容量を入れてはいけない。また、符号を反転するだけで任意の目的関数を最小カットにできるわけではない。

## 2変数の劣モジュラ分解

異なる要素 $u,v$ の選択に応じたコストを、行が $x_u$、列が $x_v$ の表で表す。

$$
C=\begin{pmatrix}C_{00}&C_{01}\\C_{10}&C_{11}\end{pmatrix}.
$$

例えば $C_{01}$ は「$u$ を選ばず、$v$ を選ぶ」ときのコストである。ここでは各成分が有限値の場合を扱う。

### 劣モジュラとは

集合関数 $F$ の劣モジュラ性は、任意の集合 $A,B$ に対して

$$
F(A)+F(B)\ge F(A\cup B)+F(A\cap B)
$$

が成り立つことをいう。これは、要素を追加したときの値の増分が、追加先の集合が大きくなるほど大きくならない性質である。

2変数では $A=\{u\},B=\{v\}$ とした条件だけが本質的で、次の不等式になる。

$$
C_{00}+C_{11}\le C_{01}+C_{10}.
$$

これは、両方を選ぶ・両方を選ばない場合のコストの和が、片方だけを選ぶ2通りのコストの和以下であることを表す。個々のコストの大小を主張しているわけではない。

ここで

$$
w=C_{01}+C_{10}-C_{00}-C_{11}
$$

とおくと、劣モジュラ条件は $w\ge 0$ であり、以下の分解で辺容量を非負にできる条件そのものになる。

### 分解の導出と辺の向き

$(x_u,x_v)=(1,0)$ のときだけ $w$ を加える辺 $u\to v$ を使い、

$$
C(x_u,x_v)=k+a x_u+b x_v+w x_u(1-x_v)
$$

と表す。$(0,0),(0,1),(1,1),(1,0)$ を順に代入すると、

$$
k=C_{00},\qquad b=C_{01}-C_{00},\qquad
a=C_{11}-C_{01},\qquad
w=C_{01}+C_{10}-C_{00}-C_{11}
$$

を得る。行列では次の分解になる。

$$
\begin{pmatrix}C_{00}&C_{01}\\C_{10}&C_{11}\end{pmatrix}
=\begin{pmatrix}C_{00}&C_{00}\\C_{00}&C_{00}\end{pmatrix}
+\begin{pmatrix}0&0\\a&a\end{pmatrix}
+\begin{pmatrix}0&b\\0&b\end{pmatrix}
+\begin{pmatrix}0&0\\w&0\end{pmatrix}.
$$

- 定数 $C_{00}$ を $K$ に加える。
- $u$ の1変数コスト $(0,a)$ を追加する。
- $v$ の1変数コスト $(0,b)$ を追加する。
- $u\to v$ に容量 $w$ の辺を張る。

$a,b$ は負でもよい。1変数の変換で定数シフトするため、辺容量は非負になる。$w=0$ の場合は1変数の項だけで表せる。

$w<0$ の場合、この選択の意味のままでは最小カットで表現できない。変数の $0/1$ を入れ替えて対応できる場合もあるが、その変数が現れるすべての項と制約を変換し、再度条件を確認する必要がある。複数の2変数項を足す問題では、同じ変数対の項を合算してから条件を調べてもよい。

### 数値例

$$
C=\begin{pmatrix}2&5\\4&1\end{pmatrix}
$$

なら $a=-4,b=3,w=6$。定数 $2$ と $u$ のコスト $(0,-4)$ を処理すると、最終的な定数は $K=-2$ になり、辺は $s\to u$（容量 $4$）、$v\to t$（容量 $3$）、$u\to v$（容量 $6$）になる。

| $(x_u,x_v)$ | カット容量 | $K$ を加えたコスト |
| --- | ---: | ---: |
| $(0,0)$ | $4$ | $2$ |
| $(0,1)$ | $4+3=7$ | $5$ |
| $(1,0)$ | $6$ | $4$ |
| $(1,1)$ | $3$ | $1$ |

元の表の4成分がすべて再現される。

### 実装

```cpp
auto add_pairwise = [&add_unary]<class T>(mf_graph<T> &g, int s, int t, int u, int v, T c00, T c01, T c10, T c11, T &offset) {
    assert(u != v);
    T w = c01 + c10 - c00 - c11;
    assert(w >= 0);  // 最小化するコストの劣モジュラ条件
    offset += c00;
    add_unary(g, s, t, u, T{0}, c11 - c01, offset);
    add_unary(g, s, t, v, T{0}, c01 - c00, offset);
    g.add_edge(u, v, w);
};
```
